# 短剧上线检查清单（Skill）

**版本 v1.0.0** · 出品：**魔力喵 AIGC 工作室（Magic Cat AIGC Studio）** · 内容核对日期：**2026 年 10 月** · 许可证：MIT

> 一部短剧做完了，然后呢？这份清单把"上线"这件没人系统讲过的事，拆成了能逐项打勾的检查表。

[English →](README.md)

## 这是什么

一个可执行检查清单式 Skill，由魔力喵 AIGC 工作室基于各平台公开规则文件与一线制作实操经验整理，覆盖从资质盘点到二轮授权的完整上线链路。配合支持 Skill 的 AI Agent 使用：把 SKILL.md 交给你的 Agent，它会在你准备上线、入驻平台、签约、被驳回排查时，逐节带着你过检查项。

## 适用人群

- 做 AI 短剧 / AI 漫剧 / 竖屏短剧的个人创作者与制作团队
- 剧已经能做出来、但卡在"怎么上线、去哪上、钱怎么结"的人
- 缺 IP、想走正规免费 IP 通道（番茄、阅文、咪咕、微信公众号小说等）的人

## 包含什么

`SKILL.md` 一个文件，14 节检查清单，每项带判定标准：

0. 三个认知校正（独家怎么算、微短剧 20 分钟分界、AI 标识）
1. 资质盘点
2. 平台选择决策（四种"物种"、默认分发顺序）
3. 抖音版权中心三身份
4. 签约模式与违约条款
5. 权属材料（AI 剧四件套、时间戳）
6. 双版本制作与出厂检查
7. 上传全流程
8. 审核避坑与备案分档
9. 其他平台逐家要点（快手 / 微信生态 / 爱奇艺 / B站 / 大屏三家）
10. IP 四通道（含 2026-10 新增的微信公众号小说通道）
11. 变现与结算
12. 二轮授权、出海、大屏与防盗版
13. 互动剧新品类观察
14. 失效预警（哪些规则最易变、复核节奏）

## 怎么用

1. 下载 `SKILL.md`；
2. 放进你所用 Agent 的 Skill 目录（或直接把全文贴给任意 AI 助手当操作规程）；
3. 对它说"我有一部 AI 漫剧要上线"，它会从第 0 节开始逐节带你核对；
4. 任一节有检查项不过，先停在该节，不要跳步。
